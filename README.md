# verisolv —— 一个会自己复核自己的非线性结构仿真智能体

> 2026 年江苏省高校 AI+科学与工程创新实践黑客松 · 参赛编号 **U311** ·
> 队伍 **牛顿-拉弗森不收敛救助站**（本科生组）· 独立完成

非线性有限元求解器有一种**沉默的失败**：迭代收敛了，但收敛到了**另一个平衡分支**上——
求解器报告"成功"，工程师拿到一个漂亮的数字，**而这个数字是错的**。本项目把"怀疑"变成可执行的检查。

## 它做什么

- 总拉格朗日平面桁架有限元（Green-Lagrange 应变 / PK2 应力 / 一致切线刚度），Newton-Raphson，载荷 + 位移双控制。
- **四道验证闸门**（残差重建 / 全局力-矩平衡 / 路径连续性 / 步长加密复算）+ **模型检查器**（不跑分析，查良定性与量级合理性）+ **会升级策略的修复链**（切控制变量 / 细化步长 / 线搜索 / 稳健组合）。
- 一个 20 案例标注库，**根因按构造已知**，用来诚实地报告"诊断器在哪里对、在哪里错"。

## 怎么跑

```powershell
$env:PYTHONIOENCODING = "utf-8"
Set-Location <项目根>            # 例：<项目根>
$py = "<Python 解释器>"          # Python 3.12+，需 numpy
& $py -m verisolv models            # 列出模型
& $py -m verisolv repair --model von_mises_truss --control load --n-steps 10   # 完整闭环
& $py -m verisolv cases             # 20 案例库（较慢）
& $py -m verisolv checkmodel --model von_mises_truss   # 不跑分析的模型检查
```

AGH 插件（6 个工具）安装与详细可复现说明见 `docs/reproduce.md`。核心包仅依赖 `numpy`，可脱离 AGH 独立运行。

### 关于极限载荷的两个数字

项目早期文档里出现过 **7957.7 N**，那是 **40 步**采样的值。极限载荷是位移控制路径上
**离散采样点的最大值**，步长越细越接近真值：

```
40 步  → 7957.60 N
80 步  → 7958.24 N
120 步 → 7962.69 N
400 步 → 7963.01 N
闭式解（200,001 点）→ 7963.2 N
```

**提交材料统一用 ≈ 7963 N**，并注明它是采样最大值而非解析极限。40 步的 7957.7 N 偏小 5.5 N
（0.07%），不单独引用。

## 诚实声明（不可美化的四条）

1. **四项验证检查里，`residual` 与 `global_equilibrium` 复用同一个 `assemble()`**，不算完全独立；
   真正独立的外部对照只有**解析解**与**独立库交叉验证**两项。
2. **两类错误原理上检测不到**（载荷方向反向、单位量级写错）：数值完全自洽，只是答错问题。
   其中 B02 的实例（×1000 量级）被 `scale_consistency` 在位移超出小应变适用域时系统性抓到，
   但"单位写错"这一类别本身仍不可检测——实测 ×10 量级同类滑移完全静默（`tools/acceptance_scale_fix.py`：
   `-500,000 N → PASSED`，`-5,000,000 N → FAILED`）；可检测的是"载荷超出结构适用域"这一后果，不是"单位写错"这一原因。
3. **截面面积的量级错误，四道数值闸门与模型检查器全部放行**（`tools/verify_audit_findings.py` 实测）：
   面积放大 1000 倍时位移小 1000 倍，而 `check_model` 报 `ok`、验证报 `verified`。
   原因：`material_plausibility` 检查 E / ρ / f_y，**不检查 A**，因为面积是**尺度参数**——
   不存在"物理上不可能的截面面积"，只存在"与设计意图不符的面积"。这属于意图类错误，
   与载荷大小、载荷方向同类，需要人对照原始设计意图，不是检查器能判的。
   **同一类盲点还有两个（2026-10-11 外部评审独立发现，本轮构造验证，见 `docs/verification.md` 第八节）**：
   ① **模量在量级带内的错值**——E = 21 GPa（默认 210 GPa 的 1/10，仍在 `material_plausibility`
   带宽 1e6–1e12 之内），四道数值闸门全过 + `verified`，位移错 ~9–10 倍（实测：位移控制到
   −0.15 m，峰值载荷因子 0.0397 vs 0.3968，差 10.0 倍）；② **载荷全加在全约束支座节点**——
   结构零响应，四道数值闸门全过 + `verified`。
   另：**位移控制下 `step_refinement` 闸门近乎空转**（终点强加、必然相同；真正变化的
   路径峰值载荷不被比较）。
4. **`verdict=verified` 只证明数值自洽，不证明满足设计约束。** 优化器把
   `verdict=verified` 与"应力 ≤150 MPa、挠度 ≤20 mm、屈曲安全系数 ≥2.0"写在同一声明里，
   容易读成前者涵盖后者。实际分工是：`verify()` 检查**数值自洽**（残差、平衡、路径、步长）；
   `optimize.evaluate()` 检查**设计约束**。两者是不同的问题，`verify()` 从未接收 `Constraints`。
   另外 `pattern_search` 是坐标模式搜索，**不保证全局最优**——"128.72 kg"是当前搜索找到的
   最轻可行设计，不是数学意义上的最优解。

详见 `docs/verification.md` 与 `docs/test-cases.md`。

## GCI / MMS 的诚实定位（第五轮更正，2026-10-11）

我们实现了 GCI（Roache / ASME V&V 20）与 MMS 尝试，**但都没有得到可用的误差带**：

- **GCI 公式第一版实现错误（观测阶比值方向反），由外部评审发现，现已修复**；
  修复后用独立的、不共享被测代码的判据（`tools/verify_gci_formula.py`，按构造已知阶的
  序列）重新验证。修复后，真实序列 `n = 40/80/160`（峰值载荷 7959.45 → 7960.52 → 7963.14 N，
  增量递增、非收敛特征）被闸门**正确判定为 `reject`**（观测阶 −1.28，非正）。
  我们**没有量化的离散误差带**。此前误报的 `GCI(fine) = 0.00485 %`（源自符号反的公式，
  且样本增量递增）是**无效数字，已全部撤回**（见 `docs/fixes-round5.md`）。
- **MMS 做不了：我们的模型没有空间网格，而 MMS 的核心是空间细化测阶。**
  第一版 MMS 工具（`tools/mms_verification.py`）被评审发现**不是有效 MMS**
  （制造源项从未注入求解器；SymPy 推导两处错误；`theory_p=1` 与饱和实测矛盾），
  已**撤回其有效性声称**，该工具保留仅作步长细化稳定性观察（见 `docs/mms.md`）。

**我们不声称任何误差带或收敛阶。**
