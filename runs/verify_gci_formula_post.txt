==============================================================================
D. Algebraic check of the asymptotic ratio
==============================================================================
  claimed identity (legacy, absolute form): asymptotic_ratio == r^(2p)?
    p=1.0: reported ratio = 1, r^(2p) = 4, legacy r^(2p)-identity = False, corrected-form identity (=1) = True
    p=2.0: reported ratio = 1, r^(2p) = 16, legacy r^(2p)-identity = False, corrected-form identity (=1) = True

  Interpretation: with the SIGN-INVERTED (pre-fix) order formula the legacy
  absolute-form ratio equals r^(2p) exactly -- an algebraic identity, so it
  carries no information beyond p.  With the corrected formula it is
  identically 1.  Either way it is NOT an independent check, which is why it
  is no longer used as a gate.  The gate now uses the literature's relative-
  form consistency ratio GCI_32*r^p/GCI_21 (Celik et al. 2008), which for an
  observed p reduces to |f1|/|f2| -- a same-magnitude sanity check only.
