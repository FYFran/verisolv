## 0. 调研结论摘要（这些是计划的依据，不是建议）

### 学科现状

- **ASME V&V 10**（固体力学）与 **ASME V&V 20**（CFD/传热）是官方标准。
- 术语是有严格定义的：**代码验证（code verification）** 证明"方程解得对"，
  **解验证（solution verification）** 量化"这一次算的数值误差有多大"，
  **确认（validation）** 证明"解的是对的方程"，**标定（calibration）** 与**预测能力**是另外两件事。
- **MMS（制造解法）** 是代码验证的金标准：构造一个人为的解析解，符号推导出源项，
  然后测量**观测收敛阶**是否等于理论阶。**它不需要参考解、不需要实验、不需要另一个软件。**
- **GCI（网格收敛指数）** 是解验证的标准做法：至少三套按固定比 r≥1.3 细化的网格，
  算出观测阶 p、理查森外推值、以及一个**百分比形式的离散误差带**。

### 三篇 agentic-FEA 论文的共同缺陷（这是我们真正的机会）

| 论文 | 验证做到什么程度 |
|---|---|
| Wilke, [arXiv 2604.06788](https://arxiv.org/abs/2604.06788) | 四道 generator-critic 闸门（含"粗网格 vs 细网格"对比）——**但没有观测收敛阶，没有 GCI** |
| AbaqusAgent, [arXiv 2606.00138](https://arxiv.org/abs/2606.00138) | "结果准确度"主要是**和 Abaqus 基准比**，即**代码对代码**——无 MMS、无 GCI |
| HELM, [arXiv 2606.12025](https://arxiv.org/abs/2606.12025) | **人工目视检查** |

**三篇都没有量化的数值不确定度带。**

### 一句可以直接用的话

> 我们不主张更好的智能体架构——文献里的架构都收敛到同一个 75–93% 区间。
> **我们主张一个当前 agentic-FEA 文献里没有的验证闸门，并测量它的成功指标捕捉不到的那个失败模式。**

## 2. 执行分级（**把布尔值升级为"你有权声明什么"**）

文献里（femis-skill 的 governance 框架）的做法是把结果分成**执行模式**，
每个模式规定了**强制闸门**和**绝不允许的声明**：

| 模式 | 强制闸门 | **绝不允许** |
|---|---|---|
| **SMOKE** | 求解完成、结果可读 | **声称任何工程数字** |
| **DEBUG** | 针对症状的那一个决定性测试 | 把诊断性求解当结果 |
| **ENGINEERING** | 单位、平衡、收敛、关注量提取 | 声称签核；报告奇异性峰值 |
| **SIGNOFF** | ENGINEERING 全部 **+ GCI + 渐近区 + 误差界** | 跳过任何闸门 |

**并且采用三值闸门**（Wilke v2 在 v1 的 `{0,1}` 基础上加了 `½`）：
**pass / conditional-pass / reject**。`½` 的语义是"我有个数，但我不能完全担保，我把它标出来"。

**交付**：
1. `verisolv/verify.py` **新增**一个 `claim_level` 字段（不动现有闸门逻辑），
   根据哪些闸门通过、GCI 是否存在，返回 `smoke / debug / engineering / signoff`。
2. CLI 和 AGH 插件的输出里**明示这个级别**。

**验收**：20 个案例全部能报出级别；`repair` 在极限载荷场景下应报 `engineering`，
在没有 GCI 之前**任何情况都不允许报 `signoff`**。

**风险**：低。纯增量，不动闸门。

## 3. GCI 闸门（**本轮最高价值的技术项**）

### 为什么

我们的"步长细化"现在只能说"两次一致到 1e-10"——**那是个布尔值**。
文献要求的是**量化的离散误差带**。这是三篇 agentic-FEA 论文都没有的东西。

### 做什么

在 `verify.py` **新增**（不改 `check_step_refinement`）：

```
用固定的细化比 r ≥ 1.3，取三套步长（例如 n_steps = N, 1.3N, 1.69N）
对同一个关注量 Q（先用"极限载荷"和"载荷因子"两个）
计算：
  观测收敛阶  p    = ln|(f3-f2)/(f2-f1)| / ln(r)
  理查森外推  f_exact ≈ f1 + (f1-f2)/(r^p - 1)
  GCI_fine    = 1.25 * |f2-f1|/(r^p-1) / |f1|      （相对形式，Fs=1.25）
  渐近区判据  asymptotic_ratio = GCI_coarse / (r^p * GCI_fine)  应 ≈ 1
```

**必须实现的失败处理**（文献明确指出这些是 GCI 的已知陷阱）：
- `r` 不是常数 → 拒绝计算，报"细化比不固定，观测阶不稳定"
- 不单调收敛 → 拒绝外推，改为**给出振荡范围**（不要硬套公式）
- `p` 远离理论阶（例如 < 0.5 或 > 4）→ 报 `conditional`，说明"可能未进入渐近区"
- **每个关注量单独报 GCI**——位移收敛了不代表应力收敛了

### 交付

1. `verisolv/gci.py`（新文件，约 120 行）
2. `verify.py` 里**新增**一道 `gci` 闸门（可选启用，默认开）
3. `defaultdict`/输出里带 `gci_fine_pct`、`observed_order`、`asymptotic`
4. `tools/check_gci.py` —— 用已知收敛阶的算例验证 GCI 实现本身是对的
5. AGH 插件：`verisolv_repair` 的输出里带上 GCI 带

### 关键约束

- **不许声称 GCI 是"误差上界"。** 它是**基于渐近假设的误差估计**，
  文献对它的批评正是"给出虚假的严谨感"。措辞必须是"离散误差估计"，不是"保证"。
- **我们的"细化"不是网格细化，是载荷步细化。** 在文档里必须说明这个区别，
  并说明为什么它仍然有意义（同一个离散化参数、同一套方程）。
  **不要假装我们做了网格收敛研究。**

**验收**：
- 一个已知收敛阶的算例（例如线性问题在步长细化下应接近某阶）能算出合理 p
- 振幅不单调时**不崩溃**且如实报告
- 20 个案例重跑，**10 个回归基线数字不变**（GCI 是新增闸门，不应改变既有结论）

**风险**：中。新增文件 + 新增闸门，理论上不动既有逻辑，但必须验证基线。

## 4. MMS 代码验证（**如果第 3 项做完还有时间**）

### 为什么

**这是唯一一个验证"我们的算子实现"而不是"我们的模型设置"的技术。**
闭式解对照和跨库对照都做不到这件事。

### 做什么

对 2 节点桁架单元做 MMS：

1. 选一个人为的位移场（**不需要物理意义**）
2. 用 **SymPy** 符号推导出对应的等效节点力（源项）
3. 施加这个源项和边界条件
4. 在**网格细化**下测量位移的观测收敛阶
5. 与**理论阶**比较

**文献里的关键事实**：Aycock/Rebelo/Craven 在商业有限元上做过弹性静力学的 MMS，
发现线弹性位移是**二阶**收敛，而有限应变在**增量细化**下是**一阶**收敛。
**我们的单元是 Green-Lagrange 几何非线性，所以应该验证的是这个。**

### 交付

`tools/mms_verification.py` + `docs/mms.md`

### 诚实边界（必须写）

- MMS 验证的是**收敛阶**，不是物理正确性
- 我们只做桁架单元，不做梁/壳
- 如果 SymPy 推不出来，**如实报告失败**，不要硬编一个源项

**验收**：能报出观测阶和理论阶，两者接近（或如实报告不接近及原因）。

**风险**：中高。SymPy 推导可能失败。**做不出来就停下报告，不要伪造。**

6. 许用值？是与一个被点名的准则比，还是与一个裸数字比？
7. 我是不是悄悄替人做了决定？（选了载荷工况、许用值、简化处理？）
   如果是——停，升级给人。

第 7 条是我们实测出的"意图类错误"的正式版本（载荷方向、单位、面积量级全都抓不到）。

## GCI 实现的核心公式（供队长复核）

```
# f1=coarsest, f2=medium, f3=finest（coarsest-to-finest 顺序）
p       = ln((f3 - f2) / (f2 - f1)) / ln(r)
f_exact = f3 + (f3 - f2) / (r^p - 1)
GCI_coarse  = 1.25 * |(f2 - f1) / (r^p - 1)|
GCI_fine    = GCI_coarse / r^p
asymptotic_ratio = GCI_asymptotic / GCI_fine   # 应趋近 1
```

失败处理：
- `p ≤ 0` → reject（非单调或非渐近区）
- 非单调（f2 在 f1,f3 之间）→ reject + 振荡范围（min,max）
- `p < 0.5` 或 `p > 4` → conditional（可能未进入渐近区）
- 退化（|f3-f2| < 1e-12 × scale）→ reject（误差低于可测阈值，是好消息，但不报 GCI）
- 非几何步长（r 不固定）→ reject，不做外推
