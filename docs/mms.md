# MMS 尝试记录（未成功，已撤回）

> **状态：撤回（2026-10-11，第五轮）。** 外部对抗性评审发现本文件描述的
> "MMS" **不是有效的 MMS**；队长决定**撤回其有效性声称，不修**。
> 本文档保留为尝试记录，逐条列出评审指出的错误，并说明根本原因。
> **本项目不声称任何 MMS 收敛阶。**

---

## 1. 尝试了什么

- 对 `cantilever_truss`，强加线性制造位移场 `u(x) = a·x`（`a = 0.01`），
  用求解器的**位移控制**强加该位移，测量**载荷因子**（因变量）在
  `n_steps = 10, 20, 40, 80` 四个分辨率下的序列。
- 理论阶取 `p_theory = 1`（Green-Lagrange 增量位移控制的一阶估计）。
- 实测：序列在机器精度饱和（相邻分辨率载荷因子相对差 ~1.4e-11），
  `observed_p = null`（不可测）。
- SymPy 符号推导"等效节点力"（`tools/mms_verification.py` 的
  `sympy_source_term()`）：`N = E·A·a`，`f_i = -N/2`，`f_j = +N/2`。

## 2. 评审指出的三处错误（逐条）

1. **制造源项从未注入求解器。** 位移是**强加的**（位移控制边界值），
   不是"解出来的"。真正的 MMS 要求：制造解 `u_m` 是**带源项 q(u_m) 的
   载荷问题**的解，把 `q(u_m)` 加进离散方程，再检查 `f_int(u_m) ≈ q(u_m)`。
   本工具没有做任何这件事——SymPy 推出的"源项"从未进入求解器，
   所测载荷因子只是强加位移的因变量，**不构成对 `f_int = q` 的任何检验**。

2. **SymPy 源项推导有两处代数错误**：
   - **应变应为 `a + a²/2`，不是 `a`。** 制造场 `u = a·x` 在杆长度 `L0` 上
     的 Green-Lagrange 应变是 `ε = du/dx + ½(du/dx)² = a + a²/2`；
     `sympy_source_term()` 用了线性化的 `ε = a`，丢掉 O(a²) 项。
   - **节点力应为 `±N`，不是 `±N/2`。** 两力杆在其自身变形构型下是二力构件，
     节点等效力是 `f_i = -N`、`f_j = +N`（`N = E·A·ε`，`ε` 取上面的正确值）；
     推导块写的是 `∓N/2`，差 2 倍且应变又错，两处叠加。

3. **"`theory_p = 1`" 与饱和的实测自相矛盾。** 若理论阶真是 1，
   `n=80` 与 `n=10` 的载荷因子差应为 O(1/10) ~ 10% 量级，
   而不是实测的 1.4e-11 饱和。饱和与"线弹性算子在小位移下
   Newton 单迭代收敛、载荷因子对步数不敏感"一致——
   这恰恰说明 `p_theory = 1` 的设定本身就不对。

## 3. 根本原因（为什么建议"撤回、不修"）

**MMS 测量的是空间离散的观测收敛阶，而我们的模型没有空间网格。**
节点是给定的，唯一的离散化参数是**载荷步数**（时间/载荷方向的增量），
**没有网格可细化，就测不了空间收敛阶**。修它需要改单元定义或引入网格，
超出半天预算，且会触及冻结的求解器内核（`fem.py`/`solver.py`）。

这与 GCI 的处境是同一个问题：我们实现了 GCI 公式（第一版还符号反了，
已由外部评审发现并修复），但**在真实问题上未能得到可用误差带**；
MMS 则更彻底——**框架本身不支持**。

## 4. 明确声明

- **这不是一个有效的 MMS。我们不声称任何收敛阶。**
- `tools/mms_verification.py` 保留，但**已加显著头部警告**，
  说明它测的不是 MMS，只可做"步长细化稳定性观察"（1.4e-11 饱和
  作为步长稳定性事实仍可如实引用，但**不得**标为 MMS）。
- 所有"MMS 验证通过 / 已验证 / 收敛阶测量"的表述，
  已从 `EVIDENCE.md`、`README.md`、`docs/upgrade-report.md`、
  `COMPLETION-SUMMARY.md` 撤回。

## 5. 若将来要做一个有效的 MMS，需要什么（记录，非本轮承诺）

- 在冻结的 `fem.py`/`solver.py` 之外引入**可细化的空间网格**
  （例如把单根杆换成若干子杆），或
- 允许往求解器**注入源项**（在 `fem.py` 的 `assemble()` 上加 `q(u)` 项）。
  两者都触及冻结内核，需单独立项，不在本轮范围内。
