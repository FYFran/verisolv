## 1. 项目是什么

**项目名：verisolv —— 一个会自己复核自己的非线性结构仿真智能体**

### 它解决的问题

非线性有限元求解器有一种**沉默的失败**：迭代收敛了，但收敛到了**另一个平衡分支**上。
求解器报告"成功"，工程师拿到一个漂亮数字，**而这个数字是错的**。

传统做法靠工程师的经验去怀疑。这个项目把"怀疑"变成**可执行的检查**。

### 它的做法

四道验证闸门 + 一个模型检查器 + 一个会升级策略的修复链：

| 组件 | 作用 |
|---|---|
| `verisolv_solve` | 跑一次非线性分析，返回原始结果 |
| `verisolv_verify` | 跑分析 + 四道验证闸门，给出 verified/suspect/rejected |
| `verisolv_repair` | 完整闭环：求解→验证→诊断→升级策略→再验证 |
| `verisolv_checkmodel` | **不跑分析**，只检查模型是否良定（机构、材料量级、约束） |
| `verisolv_cases` | 跑 20 个标注案例，返回每个案例的真值与实际观测 |
| `verisolv_models` | 列出可用模型 |

### 诚实声明（你必须继承这个立场）

这个项目**已经如实记录了自己抓不到的东西**：

- 四项检查里**有两项复用求解器自己的装配代码**，不算完全独立。真正独立的外部对照是**解析解**和**独立库**两项。
- 有**两类错误原理上检测不到**：载荷方向反向、单位量级写错。它们的数值完全自洽，只是答错了问题。

**你在任何输出里都不许美化这两点。** 这是项目的立身之本，也是评分里"验证严谨性"那一项的核心。

## 4. 任务 A —— 盲测诊断（**优先级最高**）

### 4.1 为什么做这个

赛事要求的 (c) 项"**Agnes 模型参与核心任务证据**"目前是空的。

已经做过的 AGH 任务（调工具、写文档、拒绝编造数据）**只能证明模型是个称职的操作员**，
不能证明它参与了核心工作。

**核心工作是：判断"系统该不该抓到某个错误"。** 这是确定性代码做不到的判断——
代码只会报 `ok` 或 `ill_posed`，它说不出"这是一类新的、需要用新检查才能覆盖的错误"。

### 4.2 你要做什么

下面有 **8 个注入故障**，是**案例库里没有的**新类型。对每一个：

1. 用 Python 构造出这个故障模型（代码在第 4.4 节）
2. 调用 `verisolv_checkmodel` 和 `verisolv_repair`（或 `verisolv_solve`）
3. **记录系统实际报了什么**（原文，不许改写）
4. **自己做判断**：系统**该不该**抓到它？为什么？
5. 如果没抓到，**说清楚需要哪一类新检查**才能覆盖

### 4.3 八个故障与标准答案

> ⚠️ 下面的"标准答案"是出题人写的，**不是给你抄的**。
> 你要独立跑出系统的实际反应，然后**把实际反应和标准答案对照**，说明一致或不一致。
> **如果实际结果和标准答案不符，如实写，不许改标准答案来迁就。**

| # | 故障 | 怎么造 | 出题人的判断 |
|---|---|---|---|
| F1 | **支座沉降** | 给某个支座节点一个强制位移 | 当前 `Model` 的约束只能锁死（位移=0），**无法表达强制非零位移**。系统会报告"零位移、收敛、验证通过"——**假阳性**，需要"指定位移边界条件"功能 |
| F2 | **杆件 i/j 互换** | 把某根杆的两端节点编号对调 | 静力等价，**数值结果完全相同**，但应力符号约定变了。纯数值检查**检测不到**，需要"单元方向约定一致性"检查 |
| F3 | **温度预应力** | 无外载，但单元有初应变 | `Bar` **没有热应变项**，系统会把初应变当零，报告"零位移收敛"——**假阳性**，需要热载荷功能 |
| F4 | **重复节点未合并** | 两个节点坐标完全相同但不共用 | 产生**机构**（刚体模态）。`checkmodel` **应该**报 `ill_posed` + 刚体模态 |
| F5 | **约束冲突/过约束** | 同一自由度被两个方向的约束重复锁定 | 结构**稳定**（不是机构），`checkmodel` 会报 `ok`——但它会诱发虚假应力，属于**建模盲区**，需要"冗余约束检测" |
| F6 | **超出小应变适用域** | 载荷放大到让位移达到结构跨度的量级 | `check_scale_consistency` **应该**报 `suspicious`（位移远超小应变模型适用域） |
| F7 | **零刚度杆** | 某根杆的 E 设成 1e3 Pa（比泡沫还软） | `check_material_plausibility` **应该**报 `suspicious`（超出任何固体的模量范围） |
| F8 | **载荷施加在完全约束节点上** | 把载荷加在一个 6 自由度全锁的节点上 | 力学上合法，载荷被支反力吃掉，**无变形**。系统会报"收敛+验证通过"——**假阳性**，需要"载荷有效性"检查（施加点是否有自由度响应） |

**预期结果分布**（这是设计意图，不是答案）：
- 应该被抓到：**F4、F6、F7**（3 个）
- 抓不到，属建模盲区：**F1、F2、F3、F5、F8**（5 个）
- **5/8 抓不到** —— 这正说明"确定性检查的边界在哪里，为什么需要模型推理"

### 4.4 怎么构造这些模型

用项目里已有的模型和类。F4 和 F8 可以直接用现成的；其余需要你写少量构造函数。

```python
import sys
sys.path.insert(0, r"<项目根>")
import numpy as np
from verisolv.fem import Bar, Model, E_STEEL
from verisolv.models import von_mises_truss, cantilever_truss
from verisolv.checkmodel import check_model
from verisolv.solver import SolverOptions, solve
from verisolv.repair import repair, diagnose
```

参考形状（从 `verisolv/cases.py` 里的 `_cantilever` 抄）：

```python
panels, span, height = 4, 4.0, 1.0
areas = {"bottom": 2.0e-3, "top": 2.0e-3, "vertical": 1.0e-3, "diagonal": 1.0e-3}
step = span / panels
bottom = [np.array([k*step, 0.0]) for k in range(panels+1)]
top    = [np.array([k*step, height]) for k in range(panels+1)]
coords = np.array(bottom + top)
# 节点编号：底排 0..panels，顶排 panels+1 .. 2*panels+1
# 约束：{0: (True, True), panels+1: (True, True)}
# 载荷：右下节点 y 方向
```

`Bar` 的构造签名（已核对 `verisolv/fem.py`，**字段顺序如下**）：

```python
@dataclass
class Bar:
    i: int
    j: int
    area: float
    modulus: float = E_STEEL      # 210e9
    density: float = RHO_STEEL    # 7850
    group: str = "default"
    yield_stress: float = FY_STEEL  # 235e6
```

`Model` 的构造签名（已核对）：

```python
@dataclass
class Model:
    coords: np.ndarray                    # (n_nodes, 2)
    bars: list[Bar]
    fixed: dict[int, tuple[bool, bool]]   # 节点 -> (x 约束, y 约束)
    loads: np.ndarray                     # (n_nodes, 2)，形状必须与 coords 相同
    name: str = "unnamed"
```

**`Model.__post_init__` 会拒绝这几种情况**（抛 `ModelError`，来自 `verisolv.fem`）：

```
coords 形状不是 (n_nodes, 2)
loads 形状与 coords 不同
杆件引用了不存在的节点
杆件两端是同一个节点（i == j）
杆件面积 <= 0
模型一根杆都没有
```

**注意它不检查什么**（这很重要，两条已核对）：
- **不检查 `modulus`** —— 所以 F7（E 设成 1e3）能构造成功，会一路流到 `check_material_plausibility`
- **`fixed` 只能表达"锁死"或"自由"，表达不了强制非零位移** —— 这直接决定了 F1（支座沉降）和 F2 的性质
- **`Bar` 没有热应变项** —— 这直接决定了 F3（温度预应力）的性质
